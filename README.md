# ThangkaVault

This repository contains Thangka-related content and images.

## Structure

- `content/`: Main content files
- `public/images/`: Images categorized by type
  - `buddha/`: Buddha images
  - `bodhisattva/`: Bodhisattva images
  - `mandala/`: Mandala images
  - `protector/`: Protector images
  - `symbol/`: Symbol images
